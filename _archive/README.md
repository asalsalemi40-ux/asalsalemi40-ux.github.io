# Archive

Work taken off the site. Jekyll ignores folders whose names start with an underscore,
so nothing here is built or published, but every file is kept.

| Folder | What it was | Why it was taken down |
| --- | --- | --- |
| `be-natural-old/` | The first low-resolution Be Natural renders | Replaced by renders from her later boards |
| `cut-chair/` | "Cut", a clapperboard chair for film sets: page text, images and its 3D model | Dropped from the portfolio |
| `walker-frames/` | The old "Walkers for older adults" page and its walker frame images | Not wanted in the portfolio; the Walking Aids page now shows only Night Cane |

To bring a project back, move its `.md` file into `_projects/`, its images into
`assets/images/work/` and (for Cut) `cut-chair.js` into `assets/js/models/`, then give it a `field:`.
